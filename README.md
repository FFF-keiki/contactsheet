# FRAME / MAKER v8 — 画像の比率に合わせたボックス

## 変更点

- **理想・素材・結果の横3列**を維持。
- 固定されていたプレビュー画像枠の高さ（480〜720px）を撤廃。
- アップロードした各画像の**元画像の幅・高さ（ピクセル）**から枠の縦横比を求め、横長画像なら横長の枠に自動調整。
- 同一ボックスの3列は同じ高さ。異なる比率が混ざる場合、どの画像も切れないよう縦長の画像を優先。
- 1枠に複数画像を入れた場合、画像の枚数に応じて必要な高さを確保。
- 画像を削除・追加するとすぐプレビューを更新。**PNG出力も変更後のレイアウト**を反映。
- 元画像の縮小・圧縮処理なし、切り抜きなし（`object-fit: contain`）。PNGの画素数制限を超えたら自動低画質化せず出力中止。

注：元画像そのものに大きな白い余白が含まれる場合、その余白は保持されます（勝手にトリミングしません）。

## 元の仕様

- 完全フロントエンド。サーバーへの画像保存・JSON保存はなし。
- 左側入力欄の独立スクロール、ボックス追加・削除・上下移動。
- モデル名の追加・削除、モデルパラメーター／忠実度／線の太さ／入り抜きの設定。
- シート全体・ボックス単位のPNG書き出しは `html-to-image` を使用。

## GitHub → Cloudflare Pages

ZIPの `index.html`、`styles.css`、`app.js` を既存の公開ディレクトリへ上書きして、GitHubにコミットしてください。Cloudflare Pages側のGit連携が有効なら自動反映されます。ビルド不要です。

PNG書き出しに使用する `html-to-image` は CDN 読み込みです。オンライン環境で実行してください。


## v10 変更点
- 各ボックスは「理想」「素材」「結果」を各1枚のみ登録
- 複数比較はボックス追加で縦に並べる方式
- モデルパラメーター / 忠実度 / 線の太さ / 入り抜き は「入力なし」を選択可能
- 入力なしの項目はプレビューとPNG出力で表示しない
