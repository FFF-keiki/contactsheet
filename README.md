# FRAME / MAKER — コンタクトシート作成ツール

Cloudflare Pages対応の静的なコンタクトシート作成サイトです。画像・テキストをブラウザ内で並べ、シート全体／個別ボックスをPNG出力します。

## 仕様

- 画像アップロード（MODEL / REFERENCE / RESULT複数枚）とプレビュー
- ボックス追加・削除・並び替え、タイトル、タグ、プロンプト、メモ
- PNG保存（`html-to-image`）、画像は元ファイルをブラウザ内で参照し、アップロード時に圧縮・縮小・再エンコードを行わない
- JSONの保存／読込、R2、D1、サーバーへの画像送信は一切なし
- 画像データをローカルストレージへ保存しない。リロードすると編集内容は消える

## 重要：画質と出力の限界

PNGは**可逆圧縮**です。元画像自体は一切変更されません。シートに画像を小さく配置する場合も、元画像の画素数を下回らない出力解像度になるよう `pixelRatio` を自動計算します（最低2倍）。`html-to-image` の `skipAutoScale:true` を使用し、自動で画質を落とす処理を禁止しています。

ただし、非常に高解像度の画像やボックスの多いシートでは、必要な出力キャンバスがブラウザの上限を超える場合があります。その場合は**縮小して保存するのではなく、エラー表示して出力を中止**します。ボックスを減らし、個別PNG出力を利用してください。複数画像を1枚のシートにすると、縦横の空きスペースも含めて出力が大きくなります。ブラウザごとの制限やメモリ不足で失敗する可能性もあります。

印刷向けDPIメタデータの設定は行いません。PNGの出力画素数は保存完了時に表示します。

## ローカル確認

簡易Webサーバーが必要です（`file://` 直開きはサンプル画像の取得に制限が出る場合があります）。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## Cloudflare Pages

GitHub / GitLab リポジトリにファイルをpushし、Cloudflare PagesでGit連携します。

- Framework preset: `None`
- Build command: `exit 0`（または空欄）
- Build output directory: `/`（リポジトリルート）
- Production branch: `main`

`html-to-image` はCDNから読み込むため、使用ブラウザにそのCDNへのネットワークアクセスが必要です。将来完全オフラインを求める場合はライブラリファイルをプロジェクト内に配置してください。

**社内向けの注意:** この静的サイト自体はアクセス認証を内蔵していません。社内のみ閲覧させたい場合は、公開するサイトに別途Cloudflare Accessでアクセス制御を設定してください。画像ファイルは作成中ブラウザ内のみで使用し、サーバーへアップロードされません。
