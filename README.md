# FRAME / MAKER — コンタクトシート作成サイト v6

## 変更点（v5から）
- REFERENCE（参考画像）と IDEAL（理想の画像）を上段2列に並べる
- RESULT（生成結果）をその下に大きく、横幅いっぱいに表示する
- 入力欄も REFERENCE → IDEAL → RESULT の順に変更
- 全体PNG / ボックス単体PNG出力にも同じ配置を反映
- 3種類の画像は複数登録・個別削除・ドラッグ＆ドロップ可能

## 継続している仕様
- 完全フロントエンドで動作。画像のサーバーアップロードなし
- JSON保存なし。ページ再読み込みで入力内容は消去
- 追加したカスタムモデル名の選択・削除、パラメーター（モデル0.1～1、忠実度0.05～1、線の太さ-1～1、入り抜き-1～1）
- ボックスの追加・削除・並び替え
- 左サイドバーは独立スクロール
- png出力は `html-to-image@1.11.13` を利用
- 元画像は読み込み時に縮小・JPEG圧縮しない。表示は `object-fit:contain` で非トリミング

## デプロイ手順（Cloudflare Pages / GitHub）

1. 同梱の `index.html`, `styles.css`, `app.js` をリポジトリの公開ディレクトリ直下へ配置します。
2. GitHubでコミットし `main` に反映します。
3. Cloudflare Pages のビルドコマンドを空欄（または `exit 0`）、出力ディレクトリをファイルを置いたディレクトリに設定します。
4. Git連携が設定済みなら自動デプロイされます。

ルート公開なら出力ディレクトリ `.`、`public/` 配下に配置するなら `public` を指定してください。

## 画質に関する注意

画像の元ファイルは加工しません。ただし、複数画像とテキストを1枚のPNGに配置する際はブラウザが再描画するため、元ファイルと出力PNGのピクセルが完全一致するものではありません。画像の実寸ピクセルを下回らない倍率を見積もり、PNGをロスレスで生成します。ブラウザの上限（1辺16,000px、8,000万画素）を超える場合は自動縮小を行わずエラーとします。大きなファイルはボックス単位出力がおすすめです。

HTML→PNGの変換にはネット経由で `html-to-image` を取得するため、初回表示でライブラリの読み込みにインターネット接続が必要です。会社のネットワークなどでCDNがブロックされている場合は、ライブラリファイルを別途同梱して参照先を置き換えてください。
