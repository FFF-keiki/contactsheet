# FRAME / MAKER — コンタクトシート作成サイト v7

## v7 更新内容

- 画像の分類名を **理想 / 素材 / 結果** に変更。左側の画像登録欄もこの順です。
- 各ボックスのプレビューとPNGを、**理想・素材・結果の横3列**で並べるレイアウトに変更。
- すべての画像表示領域を同じサイズ・高さにし、限られた幅の中で画像を大きく表示します。
- 画像は全体表示（`object-fit: contain`）で、意図的な切り抜きはしません。

## 継続している仕様

- フロントエンドのみ。画像や入力データのサーバー保存なし、JSON保存なし。
- ボックスの追加・削除・順番変更、ボックス単体PNGとシート全体PNGの出力。
- 左側の入力欄の独立スクロール。
- カスタムモデル名の追加・削除・選択、モデルパラメーター 0.1～1 / 忠実度 0.05～1 / 線の太さ -1～1 / 入り抜き -1～1。
- 画像は元ファイルのまま読み込み、ブラウザ内で扱います。PNG合成で`html-to-image`を使用します。

## Cloudflare Pagesで公開

`index.html`、`styles.css`、`app.js` を既存の公開ディレクトリ直下に上書きしてGitHubへコミットすると、Git連携済みCloudflare Pagesに自動反映されます。ビルドコマンドは空欄、出力先は配置した公開ディレクトリ（リポジトリ直下の場合 `.`）です。

## 画質と制限

元画像は縮小・JPEG圧縮せずに読み込みます。PNGは高解像度でロスレス合成しますが、画面内で配置される画像は再描画されるため、画像単体と完全同一ピクセルになることを保証するものではありません。元画像の画素数を下回らない倍率を計算し、1辺16,000pxまたは総画素数8,000万画素を超える場合は自動縮小せず中止します。

複数枚を同じ枠に読み込む場合は枠内にグリッド表示します。`html-to-image`本体はネットワーク経由で取得するため、PNG保存時にインターネット接続が必要です。
