# FRAME / MAKER v12 — 自動復元・高解像度PNG版

コンタクトシートをブラウザ上で作成する静的Webアプリです。Cloudflare Pages / Workers Static Assets 等の静的配信で利用できます。画像・入力値はサーバーに送信しません。

## 主な仕様

- 1ボックス：理想・素材・結果の画像を**それぞれ1枚**、横3列で表示
- 複数ボックスは縦方向に並べる。ボックスの追加・削除・上下移動に対応
- 各ボックスでカスタムモデル名、モデルパラメーター（0.1～1）、忠実度（0.05～1）、線の太さ（-1～1）、入り抜き（-1～1）を設定。パラメーターは「入力なし」も選択可能
- プロンプトとメモ、元画像ファイル、モデル名の候補、ボックス順、選択状態を**IndexedDB に自動保存**
- ページ更新・サイト再デプロイ後の再読込で自動復元（同じブラウザ／端末／サイトURLを使う場合）
- 手動JSON出力なし。R2 / D1 / Google Drive不要
- 画像は元ファイルをBlobとして保持し、読み込み時に縮小・圧縮・切り抜きしない
- 通常サイズのPNGは html-to-image、巨大なPNGは SVG分割描画とPNGの逐次圧縮で単一ファイルにする。Chrome/Edgeではファイルへストリーミング保存できる場合があります

## 配置

次の **5ファイル** を同じディレクトリに配置します。

- `index.html`
- `styles.css`
- `app.js`
- `draft-store.js` ← **自動保存に必要**
- `png-tile-export.js` ← **大型PNG保存に必要**

`index.html`を配信する場所をサイトのルートにしてください。`html-to-image` は jsDelivr CDN から読み込むため、使用時にインターネット接続が必要です。

## 大切な注意

**初回 v12 への更新**では、v11以前のサイトでブラウザのメモリ上にしか存在しない作業データは自動移行できません。今開いている旧版の作業結果は、更新前にPNGとしてダウンロードしてください。v12で読み込み直して登録した後は、入力値・画像が同一オリジンのIndexedDBに保存されます。

IndexedDBは**サーバーのバックアップではありません**。ブラウザのサイトデータ消去、シークレットウィンドウ終了、端末変更、ブラウザプロファイル変更、サイトのドメイン変更、ストレージの自動削除などでは消える可能性があります。個別のブラウザ／端末間で自動同期されません。ブラウザの空き容量や保存上限にも影響されます。画面下の「保存を保護」ボタンで永続ストレージの許可を申請できますが、ブラウザが必ず許可するとは限りません。

PNGの書き出しは**元画像を意図的に圧縮・縮小しません**。ただしブラウザ・機器のメモリ／ファイル書き込み能力・SVG描画能力・PNG形式自体の限界を超えるサイズまで保証するものではありません。非常に大きいときは「選択ボックスをPNG保存」も試してください。
