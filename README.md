# FRAME / MAKER — 画像を大きく使うコンタクトシート

Cloudflare Pagesへそのままデプロイできる、ブラウザのみで動く静的サイトです。

## 更新した仕様

- コンタクトシートの**タイトル・フッター・各ボックスのタイトル／タグを削除**
- モデルは画像アップロードではなく**テキスト入力**（モデル名、バージョン、設定など）
- 参考画像 / 生成結果画像を**2カラムで大きく表示**。生成結果が複数ある場合も各画像を大きく縦に並べる
- 初期レイアウトは**1列**。ボックス数が多い場合は2列表示も選択可能
- 画像はブラウザで直接読み込み。アップロード先、サーバー、DB、JSON保存はなし
- **シート全体／ボックス単位でPNG出力**（`html-to-image`）
- **左の入力パネルは独立して縦スクロール**。PCでは右のプレビューを表示したまま編集でき、スマートフォンでは高さを抑えた入力欄をスクロールできます。
- 元画像を**圧縮・縮小・再エンコードしない**。プレビューはCSSで表示サイズを調整するだけ

## PNGの解像度について

`html-to-image` の `pixelRatio` を元画像の自然画素数と実表示幅／高さから計算します。画像が出力時に元のピクセル数を下回らないようにし、`skipAutoScale: true` で自動縮小を禁止します。

ただし、**元画像と完全に同一の画素データをそのままPNG内に埋め込むわけではありません**。ブラウザが画像を再描画したPNGです。画素数は確保しますが、再描画で細部の補間・色表現が変わる可能性があります。「元データのバイト単位の同一性」が必要なら、コンタクトシートとは別に原画像を保持してください。

出力キャンバスが大きすぎる場合は、画質を落とさずエラー表示して処理を中止します。数が多いときは個別ボックスを出力するか、1列レイアウトをお使いください。ブラウザや端末のメモリ上限によってはそれ未満でも失敗する場合があります。

## ローカル起動

```bash
python -m http.server 8000
```

`http://localhost:8000/` を開きます。サイト出力に使う `html-to-image` はCDNから読み込んでいるため、PNG保存時に外部ネットワーク接続が必要です。ユーザー画像の外部送信処理はありません。

## GitHub → Cloudflare Pages

1. ZIPを展開して、`index.html` `styles.css` `app.js` `samples/` をリポジトリのルートに配置します。
2. GitHubへcommit / pushします。
3. Cloudflare PagesでGitリポジトリを接続し、以下を設定します。

| 項目 | 設定 |
|---|---|
| Framework preset | None |
| Build command | `exit 0` （または空欄） |
| Build output directory | `/` |
| Production branch | `main` |

**社内向け注意:** このサイトにはログイン機能がありません。社内の指定メンバーに限定するならCloudflare Access等でサイト自体にアクセス制限をかけてください。
